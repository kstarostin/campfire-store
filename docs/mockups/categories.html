Design direction (for implementation)

Interactive preview above on the standard light page canvas (#fafafa, same as Home and Catalog). Root bands use a light stone scrim with dark copy; leaf tiles keep a dark bottom gradient. Use the mockup bar to preview gradient side. Below: what to build in the app and API.

Layout — keep the vertical stack

  • Preserve today's /categories structure: one section per root category, leaves in a grid inside each section.
  • Upgrade each section into a full-bleed photo band (~22–28rem tall) with a light side gradient scrim (≈40–55% width) holding copy + leaf tiles.
  • Alternate gradient side per band for rhythm; storefront decides layout — not stored on the category record.
  • Root titleI18n is display copy only (not a link). Primary navigation to the root PLP is the Browse all pill CTA.
  • On mobile: stack copy above tiles; scrim becomes bottom-weighted so text stays readable.

Photography

  • Root image: one wide landscape per root category (1800px+ source). Kayaks example uses Unsplash zK049OFP4uI.
  • Leaf image: smaller crop per subcategory — thematic, not product packshots. Bottom gradient on tiles (dark → transparent top).
  • Serve via CDN or /img/categories/{code}.webp after local optimization.
  • Subtle Ken Burns on hover on root photo only; respect prefers-reduced-motion.

Typography & color

  • Eyebrow pill: existing nameI18n (e.g. “Kayaks”) + category icon.
  • Root titleI18n: longer motivational headline (Fraunces). Root descriptionI18n: longer supporting paragraph.
  • Leaf titleI18n: short tile headline. Leaf descriptionI18n: short hint line under the title.
  • Light scrim on root bands: stone-50 gradient → dark text + orange Browse all pill. Leaf tiles: dark bottom scrim + light text.

Page intro copy

The page-level h1 + lead paragraph stay in storefront i18n (not on the category model) — see mockup for tone.

Accessibility

  • Meaningful image.altTextI18n on root and leaf photos.
  • Ensure 4.5:1 contrast for title and description over the light scrim.
  • Focus ring on leaf tiles and Browse all CTA; entire leaf tile remains one link.

Out of scope for v1

  • Parallax scroll, video backgrounds, or per-user seasonal themes.
  • Product counts on tiles (optional later if API exposes counts cheaply).
